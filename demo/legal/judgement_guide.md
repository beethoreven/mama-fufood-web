## 這一頁在說什麼

食材判斷頁和新增紀錄時看到的圖示，是 App 依照你填的紀錄，用固定規則整理出來的結果。這一頁把規則完整公開。

> **本 App 僅供記錄與參考，非基於醫學知識做的判斷。**
>
> - 下面的規則是我們自己訂的整理方法，**不是根據醫學知識或醫學研究訂出來的，沒有醫學上的依據**，也沒有公認的規範可以依循。
> - 判斷結果只是把你的紀錄整理成比較容易看的樣子，**不是醫療判斷，不能用來判斷寶寶是否過敏**。
> - 本 App 的用途是協助你記錄；寶寶有任何反應，請諮詢醫師。

規則內建在 App 裡；規則有修改時，會透過更新 App 生效，並在這一頁說明。

## 過敏狀況

### 怎麼算

只計算有填「過敏狀況」的紀錄；沒選的紀錄不算進去。每筆紀錄依你選的項目給分：

| 你選的 | 分數 |
|---|---|
| 沒有過敏狀況 | 0 |
| 隔天發生過敏 | 0.3 |
| 當天發生過敏 | 1 |

把這個食材所有的分數加起來，除以有填的筆數，得到平均分數：

（≤ 是「小於或等於」，< 是「小於」。）

| 平均分數 | 顯示 |
|---|---|
| 0 ≤ 平均 ≤ 0.2 | 穩定 |
| 0.2 < 平均 ≤ 0.7 | 風險 |
| 0.7 < 平均 ≤ 1 | 過敏 |

### 額外的最低標示

為了不讓平均把重要的狀況沖淡，出現下列情況時，結果至少會是：

- 出現過 1 次「當天」→ 至少「風險」
- 出現過 2 次以上「當天」→「過敏」
- 出現過 2 次以上「隔天」→ 至少「風險」（只有 1 次「隔天」時，照平均分數）

### 什麼時候不顯示圖示

有填的紀錄不到 3 筆，而且從來沒有出現過「當天」或「隔天」時，紀錄還不夠，**不顯示圖示**。只要出現過一次「當天」或「隔天」，就會照上面的規則顯示。

### 例子

| 這個食材的紀錄 | 計算 | 顯示 |
|---|---|---|
| 沒有、沒有 | 只有 2 筆、沒出現過反應 | 不顯示圖示 |
| 沒有、沒有、沒有 | 平均 0 | 穩定 |
| 沒有、沒有、沒有、隔天 | 平均 0.3 ÷ 4 ≈ 0.08；只有 1 次隔天 | 穩定 |
| 沒有、當天 | 平均 0.5；出現過當天 | 風險 |
| 沒有、沒有、沒有、當天、當天 | 平均 0.4；當天 2 次 | 過敏 |

### 請記得

- **「穩定」只代表目前的紀錄沒有出現反應，不代表安全。** 過敏可能要接觸幾次之後才出現，也可能第一次就發生。
- **同一天吃了多種食材時，App 無法知道是哪一種造成反應。** 請依你的判斷標記；結果會受到你標記的方式影響。
- 「過敏」表示多次出現過敏反應，建議諮詢醫師。

## 用食反應（喜好）

### 怎麼算

只計算有填「用食反應」的紀錄。每筆依你選的項目給分：

| 你選的 | 分數 |
|---|---|
| 排斥 | -1 |
| 接受 | 0 |
| 喜歡 | 1 |

寶寶的口味會隨著多次嘗試改變，所以只看近期的紀錄：比較「最近 10 筆」和「最近 3 個月的全部紀錄」，用**筆數比較多**的那一組，算出平均分數：

| 平均分數 | 顯示 |
|---|---|
| -1 ≤ 平均 < -0.2 | 排斥 |
| -0.2 ≤ 平均 < 0.2 | 接受 |
| 0.2 ≤ 平均 ≤ 1 | 喜歡 |

### 什麼時候不顯示圖示

採用的那組紀錄不到 3 筆時，紀錄還不夠，**不顯示圖示**。這時可能是寶寶吃了兩次都排斥，也可能兩次都喜歡；次數太少，我們不下結論。

### 例子

| 採用的紀錄 | 計算 | 顯示 |
|---|---|---|
| 喜歡 6 次、接受 3 次、排斥 1 次 | (6 - 1) ÷ 10 = 0.5 | 喜歡 |
| 排斥 2 次、接受 1 次 | -2 ÷ 3 ≈ -0.67 | 排斥 |
| 排斥、喜歡 | 只有 2 筆 | 不顯示圖示 |

### 為什麼只看近期的紀錄

寶寶的口味可能會隨著多次嘗試改變，一開始排斥的食材，之後可能慢慢接受。所以早期的紀錄不會永遠決定結果。

## 腹瀉與嘔吐

頁籤「腹瀉嘔吐」裡，每個食材有兩個結果：腹瀉一個、嘔吐一個，分開算。有可能某個食材常出現腹瀉、卻沒有嘔吐。

### 怎麼算

只計算有填「腹瀉或嘔吐」的紀錄；三個選項都沒點的紀錄不算進去。腹瀉、嘔吐各自給分：有發生 1 分，沒有 0 分；選「正常」時兩個都是 0 分。把分數加起來，除以有填的筆數，得到平均分數：

（≤ 是「小於或等於」，< 是「小於」。）

| 平均分數 | 顯示 |
|---|---|
| 0 ≤ 平均 ≤ 0.4 | 正常 |
| 0.4 < 平均 ≤ 1 | 腹瀉（嘔吐那一欄顯示「嘔吐」） |

只看平均分數，沒有過敏那樣「出現過幾次就至少顯示風險」的規則。

### 什麼時候不顯示圖示

有填的紀錄不到 3 筆，而且從來沒有發生過腹瀉（或嘔吐）時，紀錄還不夠，**不顯示圖示**。只要發生過一次，就照平均分數顯示。

### 例子

| 有填的紀錄 | 腹瀉 | 嘔吐 |
|---|---|---|
| 正常、正常、正常、腹瀉、腹瀉 | 2 ÷ 5 = 0.4 → 正常 | 0 → 正常 |
| 正常、腹瀉、腹瀉＋嘔吐 | 2 ÷ 3 ≈ 0.67 → 腹瀉 | 1 ÷ 3 ≈ 0.33 → 正常 |
| 腹瀉 | 1 ÷ 1 = 1 → 腹瀉 | 只有 1 筆、沒發生過 → 不顯示 |

### 請記得

- **「正常」只代表目前的紀錄裡大多沒有發生，不代表這個食材不會造成腹瀉或嘔吐。**
- **同一天吃了多種食材時，App 無法知道是哪一種造成的。** 請依你的判斷記錄；結果會受到你記錄的方式影響。
- 寶寶腹瀉或嘔吐時，請留意有沒有脫水（例如尿量變少、精神變差），並諮詢醫師。

## 沒有圖示是什麼意思

不論過敏狀況、用食反應或腹瀉與嘔吐，**沒有圖示都代表紀錄還不夠，App 還不能判斷**；從來沒記錄過的食材也一樣不顯示。
